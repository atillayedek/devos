# Security policy

DevOS is early-stage software and not yet suitable for production use.

To report a vulnerability, please use GitHub's
[private vulnerability reporting](https://github.com/atillayedek/devos/security/advisories/new)
instead of a public issue. Include the affected component (bootloader, kernel subsystem,
syscall, userland program), steps to reproduce and the impact. We will acknowledge the report
and coordinate a fix before public disclosure.
